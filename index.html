I’m a website developer, turning ideas into clean, responsive websites.

I am Tharima Sultana Keya, a full stack web developer from Dhaka, Bangladesh. I build web applications end to end: responsive interfaces with React.js and Next.js, backend APIs with Node.js and Express, and data storage with MongoDB.

I like connecting every layer: designing a clean UI, building the API behind it, structuring the database, and deploying the finished app so anyone can use it. My economics background helps me think analytically and break big problems into clear steps.

Alongside development, I have skills in digital marketing, graphic design and data entry. I am looking for an internship or junior full stack role where I can keep learning and contribute to a real team.
