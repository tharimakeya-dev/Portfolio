# Tharima Sultana Keya | Portfolio

My personal portfolio website showcasing my projects, skills, experience and education as a **Full Stack Web Developer**.

🔗 **Live site:** [https://tharimakeya-dev.github.io/Portfolio/]

## Features

- **Responsive design:** works on mobile, tablet and desktop
- **Single-page navigation:** quick links to Home, About, Skills, Projects, Experience, Education and Contact
- **Filterable skills section:** browse skills by category (Frontend, Backend, Database & Auth, Tools & Deploy, Other)
- **Featured projects:** each project has a short description, tech tags, a live demo link and a code link
- **Experience and education timeline:** my learning journey and background at a glance
- **Contact section:** contact details, social links and a message form that opens your email app
- **Resume / CV access:** easy way for recruiters to find my resume
- **Availability badge:** shows that I'm open to internships and junior roles
- **Light & dark mode:** toggle between themes, and the choice is remembered

## Sections

| Section | What it shows |
